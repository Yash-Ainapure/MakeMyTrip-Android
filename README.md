# Voyago

**Voyago** is an Android travel booking application built with **Java** and **Firebase**, inspired by MakeMyTrip.  
It allows users to browse destinations, book trips, make payments, and manage bookings — all in one app.

---

## 🚀 Features
- **Browse Destinations** – Explore a variety of destinations with detailed descriptions and images.
- **Trip Booking** – Reserve trips with a smooth, step-by-step booking process.
- **Payment Gateway Integration** – Securely pay for bookings within the app.
- **User Authentication** – Firebase-based email/password login and signup.
- **Booking History** – View and manage your past and upcoming bookings.

---

## 🛠 Tech Stack
- **Language:** Java  
- **Backend & Database:** Firebase (Firestore, Authentication, Storage)  
- **Payment:** Integrated payment gateway API  
- **IDE:** Android Studio
